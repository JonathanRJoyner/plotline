- **Reset to defaults:** keeps Pen use while there is more than one pen, so a colour setup no longer falls back to its first pen, often yellow, drawing alone. With Pen use set to one pen by hand, a light first pen now gets a plot lint warning that names it.
- **Optimize:** says why when it has nothing to suggest (nothing drawn, drawings that follow the tones too little for a tone error, or every density over a limit), in the GUI, the CLI and MCP, where it used to say nothing. MCP `optimize` returns that answer with a null `error` and `patch` instead of `null`, and the CLI no longer says "no trial stayed within the target" when no target was given.
- **Fit and optimize:** an Optimize sentence goes when a new image is opened, even with the same settings, and the stage chips read done after a fit or a search instead of waiting.
