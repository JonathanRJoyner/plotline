Section: Front ends

- **Share link:** Copy link, beside Save preset and Load preset, copies a link that holds the setup (style, settings, page, paper and pens, but no image and no machine, so a link can never set the G-code your plotter runs) after a `#`, so a setup can be pasted into a forum post without a file. Opening the link loads that setup over the one the browser remembered, then clears the link from the address bar; Undo goes back to the remembered one. The part after the `#` is never sent to a server. A browser that refuses the clipboard shows the link to copy by hand.
