# Model catalogue

**Decided:** 2026-10-16

**Choice:** Designed on 2026-10-16 with [learned line models](2026-10-16-learned-line-models.md): `crates/core/src/models/catalogue.json`, changed only with a release. A model is listed only when the owner of its weights releases them under MIT, BSD, Apache-2.0, CC0 or CC BY, its training data and their licences are documented, and plotline may host a converted copy. The first entry is `teed-1` (Soria et al., ICCV Workshops 2023); its training note says that TEED was trained on BIPED, a dataset by the same first author, and that BIPED's README limits its use to non-commercial purposes while the weights are released under MIT by their author. `contour-1` (Chan, Durand and Isola, CVPR 2022) follows in its own change: its instance normalisation defeats tiling, so it will run on the whole image capped at 1024 pixels, converted from the authors' `model.zip`. Amended on 2026-10-17: `contour-1` is not hosted, because its training drawings are CC BY-NC-SA 4.0, not CC BY 3.0 as the spec said; see [contour-1 not hosted](2026-10-17-contour-1-not-hosted.md). Entries give the licence, the attribution and the training data, and say nothing about how drawings may be used. Built on 2026-10-17: `teed-1` is listed, first at commit 6b7b215 of `plotline-models` (254,517 bytes, overlap 32, converted on 2026-10-16). Changed on 2026-10-17 to commit bc9d7f9 (255,026 bytes, same overlap), whose graph has a fixed floor folded in so that blank paper reads 0: the first file drew a path on a flat white or grey picture at an ink threshold of 0.4, where nothing was. The id stayed `teed-1` because the model had never shipped; the spec's rule that a new conversion gets a new id applies once a model has shipped. The core passes a model's answer through unchanged, so a catalogue model must put blank paper at 0 in its graph, and a core test pins that. The catalogue test also requires every overlap to be a multiple of 8, so that each tile's kept centre, `TILE - 2 * overlap`, is a multiple of 16 and every tile's window starts on a multiple of 8. Nothing in the tiler depends on that alignment; the rule keeps the windows aligned for models whose layers halve the image. The test also requires every overlap to be under 256, because an overlap of 256 or more leaves no centre to keep and hangs the model stage, and 512 or more panics it. The card pictures under `web/public/models/` are drawn by `cargo run --release -p plotline-models --example model_cards -- web/public/models FILE...`, which takes model files named `<id>.onnx` that match the catalogue.

**Reason:** A user can read what a model is and where it came from before downloading it. The anime style of the same paper is left out because the source of its training sketches cannot be checked.
