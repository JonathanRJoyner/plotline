# No styles per region

**Decided:** 2026-10-16

**Choice:** plotline does not split one drawing into regions that each use their own style. This settles what the "Regions and mosaic" family in §7.2 left open; the `mosaic` style, which varies its lines' angle and spacing per region within one style, stays as built. Stacking stays a later family: two styles each drawn over the whole page in their own pen, such as line work over a tone fill, with no mask between them. It is listed in §7.2 and is not committed.

**Reason:** A region boundary shows in the plot. Each style answers tone in its own way: `waves`, `spiral` and `mosaic` start from a tone gamma of 1.9 while `hatch` and `grid` keep 1, so the same grey draws at a different darkness on each side of the edge. The auto tone response could even out the darkness, but it is off for every style, and the texture still changes at the edge. Clipping also undoes what some styles are for: `line` and `spiral` draw one unbroken stroke, and a region edge cuts it into many paths with a pen lift each. The regions need a source too. A mask painted by hand is image editing, which §4 rules out, and a mask from tone bands, superpixels or saliency puts boundaries where the user did not choose them. Every feature that works on a run assumes one style and one set of settings: presets, Looks, Optimize, the Try styles grid, plot lint, the budget solver, the CLI's `--set`, the MCP tools, the tour and the regression gallery. A second style per region would reach all of them for a result few drawings need. The most common reason to want it, fine detail in one place and a looser drawing elsewhere, is what [focus points](2026-10-16-focus-points.md) already give every style. Stacking avoids the boundary, because each style covers the whole page and plots as it was designed, and a result is already a list of pen layers. A user can stack today by exporting each drawing and plotting both on one sheet; what stacking would add is a preview of the two together and one export file, which waits until someone asks for it.
