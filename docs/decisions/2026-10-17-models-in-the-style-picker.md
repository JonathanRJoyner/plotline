# Models in the style picker

**Decided:** 2026-10-17

**Choice:** Built with [learned line models](2026-10-16-learned-line-models.md), the GUI half of [model downloads](2026-10-16-model-downloads.md). The style picker gains two tabs, Get models and Load your own, so its column of tabs now shows. Each loaded model is an entry of its own in the Styles tab: the `learned` style with `model.model` set to that model, labelled with the model's label, its licence as the note (or "your own" for a file of your own), and the model's card picture, or plain paper for a file of your own, never a trial run. With no model loaded, `learned` is one entry noted "needs a model" whose click opens Get models (amended on 2026-10-17, see [learned default model](2026-10-17-learned-default-model.md): the built-in model is always the first entry, drawn like any style, so no entry needs a model). Download shows the licence screen only while the model's current licence, attribution and training note are not yet accepted in this browser; Accept stays disabled until "I've read the licence" is ticked. A file is kept only after the engine has taken it, and Get models lists models of your own and kept files that did not load, each with Remove. The settings panel shows `model.model` as a choice of the loaded models, and the Focus chip is disabled for a style without the Image stage.

**Reason:** The spec makes each downloaded model a Styles entry, and one entry per model lets the picker pick a model in one click, as it picks a style. A contour run takes seconds, so a model's card shows its committed picture rather than a trial. Acceptance is kept per model and per hash of the licence, attribution and training note, so that a change to any of them asks again; asking again for an unchanged one adds a screen and protects nothing. Keeping only what the engine took means a reload never restores a file the engine refuses, and a kept file that stops loading can still be removed. A free text field for the model id invites typos the run would only report later, and Focus on a style without an Image stage would add points that change nothing.
