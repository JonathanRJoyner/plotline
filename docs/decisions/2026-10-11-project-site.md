# Project site

**Decided:** 2026-10-11, recorded here on 2026-10-17

**Choice:** The project's site is GitHub Pages at its default address, [jonathanrjoyner.github.io/plotline](https://jonathanrjoyner.github.io/plotline/), which the Pages workflow has deployed from `main` since the repository went public on 2026-10-12. A custom domain may come later; `plotline.page` is the candidate.

**Reason:** Pages is free, and static files are all the site needs: there is no hosted service (BRIEF.md §4), and the GUI runs in the visitor's browser (§8). Adding a custom domain later redirects the default address to it, so links already shared keep working.
