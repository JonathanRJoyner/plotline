# Reset keeps Pen use

**Decided:** 2026-10-17. Amends the brief's "Reset to defaults" row.

**Choice:** `Session::reset_settings` puts every stage of the style back to its defaults, except Pen use (the `split` stage) while the session has more than one pen. Pen use then keeps its values, and a value the user set stays the user's, so a style switch still carries it. With one pen Pen use resets with the rest. Loading a preset still starts from the style's defaults, Pen use included, before the preset's own settings apply. This holds for the GUI's Reset to defaults button, MCP `run(reset=True)` and Python `Session.reset_settings()`.

The plot lint's `unused_pens` note, which says that Pen use is set to one pen while there are more, becomes a warning when the first pen is light, a BT.601 luma over 0.6 (yellow, or a pale colour of the user's own). Its message then names that pen: "Pen use is set to one pen, so only pen 1 (Yellow, yellow) draws, and a light ink alone shows little." It keeps the patch that sets Pen use to light to dark.

**Reason:** The audit of 2026-10-16 ([F8](../audits/2026-10-16-colour-styles-audit.md#f8-the-colour-suggestion-puts-the-lightest-pen-first-so-a-reset-draws-everything-in-yellow-confirmed)) found that applying the colour suggestion and then pressing Reset to defaults left every style drawing in yellow only. The suggestion lists its pens lightest first, as the Pens dialog advises, because pens plot in list order. In one-pen mode the first pen draws everything, and the reset put Pen use back to one pen. Pen use says how the pens share a drawing, so it belongs with the pens, which a reset leaves alone, rather than with the style's look. With one pen there is nothing to share between pens, so Pen use resets with the rest, as before.

Making one-pen mode use the darkest pen instead was rejected. It would change the drawing of every saved setup with a light first pen, and the rule that the first pen draws alone is the one the Pens dialog states. The warning covers the case a reset no longer causes: a user who sets one pen by hand with a light ink first. It needs several pens because a single light pen is the user's whole choice, and the lint does not see the paper, on which a white or yellow ink can be the right pen. It is a warning rather than a note because a colour picture drawn in yellow alone wastes the plot, which is what the lint's warnings mark. Of the ten built-in inks the 0.6 limit puts only yellow (0.74) over it; orange (0.58) is the next lightest, and grey and pink are near 0.5.
